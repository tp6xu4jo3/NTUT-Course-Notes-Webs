三維參考系、旋轉與齊次矩陣

右手座標系以右手定則決定旋轉正方向。相機、世界、機械臂基座可能採用不同軸定義，必須先標明變換方向。

Rz(θ) = [ cosθ −sinθ 0 ; sinθ cosθ 0 ; 0 0 1 ]

旋轉矩陣滿足RᵀR=I、det(R)=1。先繞X再繞Z與反過來通常不同；歐拉角須明定旋轉順序。

ᵃTᵦ = [ R   t ; 0   1 ]
Pₐ = ᵃTᵦ Pᵦ
ᵃT꜀ = ᵃTᵦ ᵇT꜀

反向變換

ᵇTₐ = [ Rᵀ   −Rᵀt ; 0   1 ]

將位置轉回原座標時，不能只把平移向量改負號，還要乘旋轉的轉置。

數值示例

點(1,0,0)繞Z軸90°後為(0,1,0)，再平移(2,0,0)得到(2,1,0)。
